# 教材サイトの構成

新版はホーム、通常回10ページ、発展10ページ、各回の手引きで構成する。第11〜15回の自由課題案内はホームと科目の進め方に置く。

## ホーム

ホームは「短い科目紹介 → 講義資料 → 自由課題 → 手引き」の順にする。詳しい科目説明・演習の進め方は「科目の進め方」にまとめる。

講義資料は第01〜10回を番号順に2列、スマートフォンでは1列に並べる。カードに載せるのは回番号と講義名のみで、カード全体から本文へ進む。発展演習は本文からたどる。

薄紫の面・細い枠線・控えめな角丸を使い、回番号を小さく、講義名を太字にする。標準の余白はカード内の上下16px・左右20px、カード間12px。通常時の最小高はPC104px・スマートフォン96pxとし、長い題名では内容に応じて伸ばす。ホバーとキーボードのフォーカスで操作対象を示す。

ホームの生成は `tools/course_home.py`、表示はホーム専用の `site/course-home.css`。講義名・URL・手引きは回別原稿と `site/nav.yaml` を使う。

## 共通ヘッダー

ホーム・通常回・発展・手引きで、同じヘッダーの骨格とCSSを使う。背景は濃い紫、文字は白。内枠を本文と同じ最大幅48remにし、サイト名と本文の左端を揃える。右側の共通リンクはホームの講義資料一覧へ進む「講義一覧」だけにする。スマートフォンでも1行に収める。

全ページで画面上部に追従させ、ページ内リンクと講義の見出し帯はヘッダーの高さを考慮して配置する。サイト名からホームの冒頭へ戻る。ヘッダーと本文で共通の左右余白を使い、通常は24px、600px以下では20pxとする。

各回の「通常講義・発展」はページタイトルの直下に置く。表示中のページを下線と太字で示し、`aria-current="page"` を付ける。各回の手引きにも通常講義・発展へのリンクを置くが、全体向けの「科目の進め方」には付けない。

骨格は `tools/site_header.py`、表示は `site/site-header.css`。ヘッダーの高さとページ左右の余白もこのCSSに集約し、本文のCSSから参照する。印刷時には共通ヘッダーと回別ナビゲーションを表示しない。

## 原稿とURL

`site/nav.yaml` の各項目が回番号・本文URL名・発展URL名・手引き・配布範囲を定める。
原稿は `materials/sessions/<slug>/`、配布物は `workbook/sessions/<slug>/`。原稿のリンクはリポジトリ内の実在ファイルへの相対パスにし、生成時にサイトのパスへ変換する。

- 本文：`sessions/<slug>/index.html`
- 発展：`advanced/<advanced_slug>/index.html`
- 手引き：`guides/<guide>/index.html`
- 配布：`downloads/session-NN/`
- 図：`figures/session-NN/`

## 原稿の部品

本文のH2は「目標・問題・定式化・解説例・結果・演習・発展・振り返り・参照」。目標と参照は番号を持たない。演習は必修1・必修2、その中に問題・作業・自己確認を置く。

Pandocのfenced divで `scenario`・`given`・`point`・`ask`・`check`・`caution` を使う。`given` は `label`、折り畳みの `hint` は `summary` を指定する。実例は各回原稿を参照する。

変換は `site/lesson-boxes.lua`、骨格は `site/lesson-template.html`、表示は `site/lesson-style.css`。コードは `site/lesson-syntax.css`、数式は同梱のKaTeXを使う。SVGはソースの描画寸法をサイト生成時に16/12倍にする。

## 公開範囲

サイトへ出す原稿は登録ページだけ、配布物は `handouts` の明示一覧だけ。教員用ファイルや設計・品質記録は含めない。配布ZIPの内部も個別配布の実体と照合する。旧版の参考資料・プロジェクト支援物・実行ページは新版サイトに含めない。

## 配布ファイルのプレビュー

登録されたUTF-8のテキスト配布物は、本文・発展・手引きのリンクをクリックすると本文の上へ重ねて表示する。読み取り専用とし、ファイル名・言語・行番号・構文の色分け、全文コピー、元ファイルのダウンロード、長い行の折り返し切替を提供する。「閉じる」またはEscで元のリンクと閲覧位置へ戻る。

対象はProlog・MiniZinc・Python、MiniZincの入力、JSON、テキスト、Markdownなど文字で読める配布物。ZIPやバイナリは通常の配布リンクのままにする。Markdownはソースを表示する。

原稿のリンク先と生成HTMLのhrefは元ファイルを指したままとし、`data-code-preview` で表示用のJSONを指定する。JavaScriptが使えない場合や修飾クリックでは元のリンクを開く。読み込みに失敗してもダウンロードを利用できる。

`tools/code_preview.py` が登録した配布物だけを `previews/session-NN/<ファイル名>.json` へ生成する。構文強調は既存Pandocを一括で使い、表示の本文が元のファイルと一致することを生成時・検査時に照合する。元ファイルの内容とファイル名は変更しない。表示・操作は `site/code-preview.css` と `site/code-preview.js`、色は本文と共通の `site/lesson-syntax.css` を使う。
