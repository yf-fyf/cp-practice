# 教材のレビュー

現在は新版の人手レビュー前。移植後の正本は、このリポジトリの `materials/` と `workbook/` である。旧版のレビュー判定を新版へ引き継がない。

## 読む順序

1. [回割り](curriculum-2026.md) と対象回の本文を読む。
2. 公開される本文・手引き・配布物だけで、開始、編集、実行、自己確認、発展の選択をたどる。
3. 目標・説明・必修演習の対応、未説明の記法、ヒントと自力で考える部分、前後の接続、100分での分量を確認する。
4. 原稿とモデル・入力・期待結果を照合し、必要な実行検証を行う。自己確認を提出や完了承認へ読み替えない。
5. 指摘はファイル・場所・影響・修正候補とともに記録し、採用したものをこのリポジトリで修正する。

Prologは第01回の手引き、MiniZincは第02回、Z3は第09・10回の手引きの実行方法を使う。静的な `make check` と、ソルバー実行、表示確認、人手レビュー、授業試行は区別する。実行していないことを成功と報告しない。

## 記録と公開範囲

教員用解答・隠しテスト・評価資料・品質記録は非公開の `../cp-practice-design/teacher/` に保持する。公開資料だけを読むレビューでは参照しない。技術照合で非公開の検証を使う場合は、その入力が今回変更した公開側のファイルを読んでいることを確認する。古い複製を検証して現在の原稿が通過したと扱わない。

記録には対象リビジョンまたは未コミット差分、確認範囲、実行コマンド、結果、未確認事項を残す。公開を妨げる問題と改善候補を区別し、採否と公開はメンテナが判断する。学習者の個人情報や授業ログは公開側に置かない。
