## 発展1　多数の候補から一つ {#one}

二候補の「ちょうど一方」を、五候補の「ちょうど一つ」へ広げる。一つの長い論理和と、候補の各ペアを禁止する条件を生成し、候補数が変わったときの式の数も考えよう。

### 条件と式の生成

候補X1〜X5からちょうど一つを選ぶ。各候補に一つのBoolean変数を対応させ、真が選ぶことを表す。他の依存・必須指定・排他はなく、目的関数も置かない。

[one-start.py](../../../workbook/sessions/09-sat/one-start.py)と[sat_io.py](../../../workbook/sessions/09-sat/sat_io.py)を使う。変数の生成と表示、`combinations(candidates, 2)`{.python}で異なる二候補の組を作る枠は提供する。`candidates` はX1〜X5に対応するZ3変数のリスト、`s` は条件を加えるソルバーである。各ペアは重複せず、自分自身とのペアも作らない。

1. **作業1：** 候補の少なくとも一つを選ぶ条件を書く。`Or`は配列を引数に取れるので、候補のリストを渡せる。
2. **作業2：** 各ペアについて両方選ぶことを禁止する条件を書く。
3. 五候補で実行した後、候補数nを0・1・2・8へ変えて確認する。nはコマンド引数として提供する。

```sh
python3 one-start.py 5
python3 one-start.py 1
python3 one-start.py 0
```

::: {.hint summary="ヒントを開く：一つの論理和と全ペア"}
少なくとも一つは`Or(candidates)`{.python}。ペア`left, right`{.python}には`Not(And(left, right))`{.python}を追加する。特定の隣り合う候補だけを禁止すると、離れた二候補を同時に選べてしまう。
:::

五候補では真がちょうど一つとなり、代入は五通りである。条件数は少なくとも一つの1節と、全ペアの $n(n-1)/2$ 節。n=5なら11節になる。n=1ではその一候補が真、n=0では一つ選べないのでUNSATとなる。空の`Or([])`{.python}は偽に当たる。

候補数が大きくなるとペア数は二次的に増える。他の符号化を調べる場合は、条件数と補助変数数を分け、性能の優劣を一回の短い計測だけで断定しない。ここではまず、この生成した式がちょうど一つを表す理由を説明しよう。

## 発展2　SATの全代入 {#enumerate}

ソルバーが返した一つの代入だけを除けば、別の代入を探せる。この操作を繰り返し、これ以上ないという判定まで確認する。どの変数の値を同じと見なすかが、全列挙の対象を決める。

### 条件と表示されない変数

A＝分析画面、B＝集計、C＝保存、D＝保存しないモード、E＝履歴閲覧を真偽で選ぶ。真は選ぶこと、偽は選ばないことを表す。Eを必ず選び、Eを選ぶならC、Aを選ぶならB、Bを選ぶならCも選ぶ。CとDは同時に選ばない。Aの必須指定やFは含めず、目的関数は置かない。

完成した[features_base.py](../../../workbook/sessions/09-sat/features_base.py)と[enumerate-start.py](../../../workbook/sessions/09-sat/enumerate-start.py)、[sat_io.py](../../../workbook/sessions/09-sat/sat_io.py)を使う。列挙するのはA〜Eすべての値の組である。必修1を自分で完成させていなくてもよい。

Z3のモデル表示では、値を決める必要がなかった変数が省略されることがある。提供する`read_values`は、指定した各変数について`model.evaluate(variable, model_completion=True)`{.python}を使い、一つのモデルでの真偽を補って読む。

例えば制約を一つも加えていない変数Uは、真でも偽でもよい。モデルの表示にUがなくても「変数がない」「解がない」ことにはならない。補われた値は一例であり、それが唯一の値であるという保証ではない。

### 除外と繰り返し

`enumerate_models(s, variables)`{.python}へ繰り返しを追加する。`s` は上の五条件を入れたZ3ソルバー、`variables`は記号名からZ3変数への辞書、`read_values`の結果は記号名から通常のPythonのboolへの辞書である。

1. **作業1：** `check()`{.python}がSATなら全指定変数の値を読み、結果リストへ記録する。
2. **作業2：** 今の代入と少なくとも一変数が違う条件を追加し、再び判定する。
3. UNSATで列挙完了としてリストを返す。UNKNOWNなら列挙未完了を報告し、全解が揃ったリストとして返さない。

::: {.hint summary="ヒントを開く：一つの組だけを除く"}
各変数について`variable != values[name]`{.python}を作り、それらを`Or`で結ぶ。Aだけを違わせると、Aが同じ別解までまとめて失う。すべてを違わせる`And`も、今の一解だけの除外にはならない。
:::

期待する(A,B,C,D,E)は、(偽,偽,真,偽,真)、(偽,真,真,偽,真)、(真,真,真,偽,真)の三つである。順序に依存せず集合で比較し、各代入を五条件へ戻して独立に検査する。

比較用には `Bool` と `Solver` をZ3から読み込み、`enumerate_models(Solver(), {"U": Bool("U")})`{.python} を呼ぶ。制約なしのU一変数を列挙すると、真・偽の二通りが必要になる。一度補った値を固定された唯一の答えだと思っていないかを確認できる。モデルに載った変数だけを巡回するのではなく、列挙対象として指定した変数を使おう。

## 発展3　小さいSATソルバー {#dpll}

整数リテラルのCNFを受け取り、単位伝播と場合分けで充足代入を探す。これは探索を理解するための実装であり、Z3の内部を再現するものではない。第03回の探索器が未完成でも始められる。

### 入力と戻り値

CNFは、いくつかのリテラル（変数またはその否定）を「または」で結んだ節を、さらに「かつ」で結んだ形である。変数は1〜n番で、正整数iは変数i、負整数−iはその否定を表す。一つの節を整数のリスト、CNFを節のリストにする。0はリテラルに使わず、nは非負整数とする。

```json
{"n": 3, "clauses": [[1], [-1, 2], [-2, 3]]}
```

この入力は、変数1が真、1ならば2、2ならば3という三節の連言である。[dpll-start.py](../../../workbook/sessions/09-sat/dpll-start.py)へ`solve(n, clauses)`{.python}を実装する。[cnf_tools.py](../../../workbook/sessions/09-sat/cnf_tools.py)には入力検査と、返した代入が元の式を満たすかの検査を用意した。

SATなら、キー1〜n、値が通常のboolの辞書を返す。UNSATなら`None`{.python}を返す。0変数の充足代入`{}`{.python}と`None`{.python}を区別する。入力の節リストは変更せず、元の式による確認に使える状態を保つ。

### 単位伝播と二つの終了

部分代入の下で、真のリテラルを含む節はすでに満たされているので除ける。残りの節では偽になったリテラルを除く。未定リテラルが一つだけ残った節は、そのリテラルを真にする必要がある。これを単位伝播と呼ぶ。

- 残る節が一つもなければ、すべて満たしたので成功する。まだ値のない変数には任意の真偽を補い、全変数の代入として返す。
- 空の節が一つでも残れば、その節を真にできないので、その枝は失敗する。
- 単位節があれば、そのリテラルが真となる値を入れて簡約を繰り返す。

**作業1：** この簡約と単位伝播を実装する。同じリテラルの重複がある節は、単位かどうかを判断する前に重複をまとめてよい。入力全体が空の`[]`{.python}と、空節を含む`[[]]`{.python}を取り違えない。

### 分岐と状態の復元

単位伝播が止まっても未定の節が残る場合、その節にある未定変数を一つ選ぶ。偽を仮定した枝と真を仮定した枝の両方を調べ、一方で成功すればその代入を返す。両方失敗したときだけ、元の枝も失敗とする。

**作業2：** この分岐を実装し、失敗した枝で確定した値を次の枝へ持ち越さない。辞書をコピーして枝ごとに持つ方法でも、変更を記録して戻す方法でもよい。戻す対象は仮定した一変数だけではなく、その後の伝播で決まった値も含む。

::: {.hint summary="ヒントを開く：二つの空と枝の独立性"}
`[]`{.python}は条件なしなのでSAT、`[[]]`{.python}は満たせない節があるのでUNSAT。分岐ごとに部分代入をコピーし、元の節から簡約し直す方法なら、兄弟の枝の代入や節の削除が混ざるのを避けやすい。
:::

### 確認と根拠

まず[単位伝播の入力](../../../workbook/sessions/09-sat/cnf-unit.json)、[矛盾する単位節](../../../workbook/sessions/09-sat/cnf-conflict.json)、[復元の入力](../../../workbook/sessions/09-sat/cnf-restore.json)、[分岐しても解なし](../../../workbook/sessions/09-sat/cnf-branch-unsat.json)で確認する。各ファイルの内容と期待判定を次に示す。`n` は変数数、`clauses` は上で定めた節のリストである。

| 入力 | n | clauses | 期待 |
|---|---:|---|---|
| cnf-unit.json | 3 | `[[1],[-1,2],[-2,3]]`{.python} | SAT |
| cnf-conflict.json | 1 | `[[1],[-1]]`{.python} | UNSAT |
| cnf-restore.json | 2 | `[[1,2],[1,-2]]`{.python} | SAT |
| cnf-branch-unsat.json | 2 | `[[1,2],[1,-2],[-1,2],[-1,-2]]`{.python} | UNSAT |

復元の入力は(1∨2)∧(1∨¬2)。変数1を偽にすると矛盾し、真にした枝は成功する。最初の枝の値を残すと、成功するはずの枝を失ってしまう。返した代入を元の節へ代入して、SATの根拠も確かめる。

[cnf-compare.py](../../../workbook/sessions/09-sat/cnf-compare.py)は、二変数の重複・恒真節なしの全512式と、三変数で三節以下の3304式を真理値表で調べ、あなたの関数の判定・代入・入力の保持と照合する。補助的な検査であり、一般のすべてのCNFを試したことにはならない。

```sh
python3 dpll-start.py cnf-restore.json
python3 cnf-compare.py dpll-start.py
```

最後に、単位伝播が元の充足代入を失わない理由、真偽二枝で未定変数の全場合を覆う理由、伝播・分岐で未定変数が減り停止する理由を説明する。テストの通過と、アルゴリズムの根拠を分けて示そう。

## 選択S09b　四つの節のMaxSAT {#maxsat}

必須条件として全部を守る問題と、真になる節の個数を評価する問題を区別する短問である。5〜10分の真理値表で考え、MaxSAT専用APIや整数の最適化の操作は使わない。

### 条件と真理値表

二つのBoolean変数p・qについて、C1=p∨q、C2=p∨¬q、C3=¬p∨q、C4=¬p∨¬qという四節を考える。∨は「または」、¬は否定で、一つの節は∨で結んだ式である。[記入用の表](../../../workbook/sessions/09-sat/maxsat-work.md)を手で埋めるか、[maxsat-start.py](../../../workbook/sessions/09-sat/maxsat-start.py)を使う。

1. 四つの代入ごとに、C1〜C4の真偽と、真になる節の個数を調べる。
2. 四節すべてを必須としたSAT問題に、解があるか説明する。
3. 別の問題として、真になる節の数を最大にしたときの値と、すべての最適な代入を求める。

Python版では、入力p・qは確定した通常のboolである。ここではPythonの`or`{.python}・`not`{.python}を使ってよい。Z3へ渡す未知の記号式に同じ書き方をする場面とは区別する。

どの代入でも一節だけが偽で、残り三節は真になる。全部を必須にする問題はUNSAT、節数を最大にするMaxSATでは最適値3で四つの代入すべてが最適となる。必須と指定された条件を勝手に希望へ変えてよいという意味ではない。
