# Prolog 実行環境の使い方

第01〜02回で使う Prolog は、**ブラウザで開くだけ**で動く。
インストールもアカウント登録も要らない。

::: important
[**Prolog 実行ページを開く →**](../../tools/prolog/)
:::

処理系（Tau Prolog）は教材サイトに同梱してあるので、
ページを一度開いてしまえば通信が切れても動く。
同梱物のライセンス表記は `THIRD_PARTY_NOTICES.md` にある。

## 画面の見かた

実行ページは上から順に4つの部分でできている。

| 部分 | 何を書く・何が出る |
|---|---|
| サンプル | 各回で使う例を選んで読み込む。読み込むと編集中の内容は置き換わる |
| プログラム | 事実と規則を書く。1つの節はピリオド `.` で終わる |
| クエリ | 問い合わせを1行で書く。末尾のピリオドは省略してよい |
| 結果 | 解・`false.`・エラーが出る |

ボタンは4つある。

| ボタン | 働き |
|---|---|
| 実行（ロード＋問い合わせ） | プログラムを読み込み直してからクエリを解く。**最初の1解**まで探す |
| 次の解 | いまの探索を続けて次の解を探す。もう無ければ `false.` になる |
| 中断 | 長引いた探索を止める。押したあとで「次の解」を押すと続きから再開できる |
| リセット | 読み込んだプログラムと結果を捨てる。プログラム欄の文字は消えない |

## 基本の手順

1. プログラム欄に事実と規則を書く（またはサンプルを読み込む）。
2. クエリ欄に問い合わせを書く。
3. 「実行」を押す。結果欄に最初の解が出る。
4. 別の解があるかを見たいときは「次の解」を押す。
5. 何も出ずに探索が続くときは「中断」を押す。

たとえば次のプログラムとクエリを試す。

```prolog
drinks(aoi, cocoa).
drinks(hikaru, coffee).
drinks(tsubasa, tea).

club(aoi, photo).
club(hikaru, tennis).
club(tsubasa, brass_band).

teammate(X, Y) :- club(X, C), club(Y, C).
```

クエリ `drinks(aoi, X)` を実行すると、変数 `X` に入った値が出る。

```text
解 1: X = cocoa.
```

「次の解」を押すと、これ以上は無いことが分かる。

```text
false.
  → これ以上の解はありません。
```

`teammate(aoi, Y)` のように解が複数あるクエリでは、
「次の解」を押すたびに `解 2:` `解 3:` と続く。

### 解の読み方

- `X = cocoa.` … 変数 `X` に `cocoa` を入れれば条件が成り立つ、という意味である。
- `true.` … 変数を含まないクエリが成り立った。
- `false.` … 条件を満たすものが（もう）見つからない。**間違いという意味ではない**。

## 長い探索を止める

候補の数が多いプログラムでは、答えが出るまでに時間がかかることがある。
実行ページは探索を細かく刻んで動かしているので、
**探索中も画面は固まらず、「中断」がいつでも押せる**。
状態表示に「探索中… 3.4 秒」のように経過時間が出る。

数十秒待っても終わらないときは、たいてい候補の作り方に無駄がある。
第02回の発展サンプルのように、**属性を1つ生成するたびに手掛かりで絞り込む**と、
同じ問題でも桁違いに速くなる。

## サンプルを URL から直接開く

`?example=` にサンプルの名前を付けると、そのサンプルを読み込んだ状態で開く。
`#` でも同じように指定できる。教材ページからの導線はこの形で張っている。

| 名前 | 内容 |
|---|---|
| `facts` | 第01回 事実と規則の小さな知識ベース |
| `member` | 第02回 リストと `member` |
| `logic-grid` | 第02回 論理グリッド（4人・3属性） |
| `logic-grid-5` | 第02回 発展 論理グリッド（5人・4属性） |
| `graph-coloring` | 第02回 グラフ彩色（5地区・3色） |

```text
../../tools/prolog/?example=logic-grid
```

## 編集した内容の保存

プログラム欄とクエリ欄の内容は、ブラウザの中（`localStorage`）に自動で保存される。
同じブラウザで開き直せば続きから書ける。ただし次の点に注意する。

- 保存先はそのブラウザだけである。別の端末・別のブラウザには引き継がれない。
- プライベートウィンドウや履歴の消去で消える。
- サンプルを読み込むと、編集中の内容は上書きされる。

**残したい内容は演習ファイルへコピーして保存する。** ブラウザ任せにしない。

## 日本語入力の注意

Prolog の記号はすべて半角である。日本語入力のまま書くと構文エラーになる。

| よくある取り違え | 正しい書き方 |
|---|---|
| 全角の `（` `）` | 半角の `(` `)` |
| 全角の `，` `．` | 半角の `,` `.` |
| 全角スペース | 半角スペース |
| 全角の `＼＝` | 半角の `\=` |

日本語そのものは扱える。ただし **アトムに日本語を使うときは引用符で囲む**。

```prolog
likes(aoi, 'コーヒー').
'好き'('あおい', 'ココア').
```

引用符なしで `likes(あおい, coffee).` と書くと構文エラーになる。
コメント（`%` から行末まで）には日本語をそのまま書いてよい。

## よくあるエラー

| 結果欄に出るもの | 原因 | 直しかた |
|---|---|---|
| `syntax_error(...)` と `line(N)` | N 行目の書き方が正しくない | 節の終わりのピリオド、条件のつなぎのカンマ、括弧と引用符の対応を見る |
| `existence_error(procedure, foo/2)` | `foo` という2引数の述語が定義されていない | 綴りと引数の個数を確かめる。`member` などを使うなら `:- use_module(library(lists)).` を書く |
| `instantiation_error` | 値がまだ決まっていない変数を使った | 値が決まる条件を先に書く（生成してから絞り込む） |
| `false.` がすぐ出る | 条件が厳しすぎる／手掛かりの変換を間違えた | 手掛かりを1つずつコメントアウトして、どれが効きすぎているかを見る |
| いつまでも終わらない | 候補が多すぎる／規則が自分自身を無条件に呼んでいる | 「中断」を押す。生成の順序を変えるか、規則の停止条件を見直す |

`\+` や `!` は第01〜02回では使わない。使うと動きが分かりにくくなるので、
まずは事実・規則・`member`・`permutation`・`\=` の範囲で書く。

## 代替の環境: SWISH

実行ページが開けないときや、授業では扱わない機能（算術の拡張、CLP(FD) など）を
試したいときは、SWI-Prolog のオンライン版 **SWISH** を使える。

1. [SWISH](https://swish.swi-prolog.org/) を開く。
2. 「Program」と書かれたテンプレートを選ぶ（アカウント登録は要らない）。
3. 左の広い欄にプログラムを貼り、下の `?-` の欄にクエリを書いて実行する。
4. 解が出たあと `Next` を押すと次の解が出る。

::: warning
SWISH は外部のサービスなので、画面や仕様が予告なく変わることがある。
授業の主環境は教材サイト同梱の実行ページで、SWISH は代替・発展用である。
保存はブラウザ内にしか残らないので、成果物は演習ファイルへコピーする。
:::
