# Claude Code instructions

- This repository contains Japanese course materials for "実践・制約プログラミング" (practical constraint programming: Prolog, MiniZinc, SAT/SMT with Z3).
- Do not commit, stage, or push without explicit maintainer permission.
- Do not modify, remove, or revert unrelated existing changes.
- Do not write learner information, lesson logs, names, hostnames, IP addresses, or other environment-specific identifiers to this repository. Write paths as repository-relative, not absolute host paths.
- Keep the core part of standard-exercise answers, completed advanced-exercise code, grading rubrics, and hidden tests only in the private `../cp-practice-design/teacher/` repository. Never copy them into `materials/` or `workbook/`.
- Treat `materials/` as source material and `workbook/` as learner-facing distribution. Review learner paths from `workbook/` alone unless instructed otherwise.
- Do not normally inspect generated or dependency directories such as `.site/`, `.pages/`, and `__pycache__/`.
- The authoritative source for the session schedule, per-session goals, the three exercise tiers, and completion conditions is `design/curriculum-2026.md`. If a manuscript disagrees with it, do not silently edit the manuscript to match; ask whether the curriculum needs revising.
- Use 「第NN回」 (two-digit, zero-padded) for session numbers and 「学習者」 for learners; do not use 「受講者」 or 「学生」.
- Read `AGENTS.md` only when detailed repository navigation, document relationships, or build and test commands are needed.
- Read only the documents and topic directories relevant to the requested task.
