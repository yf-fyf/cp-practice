# 第07回 学生と研究テーマの割当（演習ファイル）

考え方・手順・ヒントは教材ページにある。ここには実行方法だけを書く。

## ファイル

| ファイル | 使うところ |
|---|---|
| `assign.mzn` | 必須演習・標準演習・発展演習。`% TODO` が2か所ある（`TODO(1)` が必須演習、`TODO(2)` が標準演習） |
| `small.dzn` | 基礎データ（6人・3テーマ・定員2） |
| `medium.dzn` | 標準データ（12人・4テーマ・定員3） |

`.dzn` はどちらも架空のデータである。実在の希望調査ではない。

## 実行する

手順は5行のカードに1か所だけまとめてある。
教材サイトの参考資料「MiniZinc 実行環境の使い方」の**手順カード（モデル + データ）**を見る。
Playground の画面が変わったときも、直すのはそのカード1か所である。

この回で使うのは次の組み合わせである。

- モデル: `assign.mzn`
- データ: `small.dzn`（必須演習・標準演習）／ `medium.dzn`（標準演習の差し替え）

最適化では途中経過の解が何本も表示される。
**最後の1本が最適解**で、末尾の `==========` が「これ以上は無い」という印である。
