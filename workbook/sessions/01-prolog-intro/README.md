# 第01回 小型論理グリッド: 宣言的に関係を書く（演習ファイル）

考え方・手順・ヒントは教材ページにある。ここには実行方法だけを書く。

- 教材ページ: [第01回](https://yf-fyf.github.io/cp-practice/sessions/01-prolog-intro/)
- 実行ページ: [Prolog 実行環境](https://yf-fyf.github.io/cp-practice/tools/prolog/)

## ファイル

| ファイル | 使うところ |
|---|---|
| `kb.pl` | 必須演習。`% TODO` が2か所ある |
| `rules.pl` | 標準演習。知識ベースは完成済みで、`% TODO` が2か所ある |

## 実行する

1. Prolog 実行ページをブラウザで開く。
2. `.pl` の中身をプログラム欄に貼り付ける。
3. クエリ欄に問い合わせを1行書いて「実行」を押す。
4. 別の解があるかを見るときは「次の解」を押す。長引いたら「中断」を押す。

インストールは要らない。ボタンの働きと結果の読み方は
教材サイトの参考資料「Prolog 実行環境の使い方」にある。

## 書いたものを残す

実行ページの内容は**そのブラウザの中にしか残らない**。
別の端末には引き継がれず、履歴を消すと消える。
書けたものはこのディレクトリの `.pl` へ写して保存する。

## 実行ページのサンプル

実行ページの上部でサンプルを選べる。この回に対応するのは
「第01回 事実と規則」で、4人分の知識ベースと `teammate/2` の規則が入っている。
必須演習を自分で書き終えてから、答え合わせに使う。
