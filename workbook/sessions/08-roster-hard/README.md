# 第08回 勤務表: ハード制約（演習ファイル）

考え方・手順・ヒントは教材ページにある。ここには実行方法だけを書く。

## ファイル

| ファイル | 使うところ |
|---|---|
| `roster.mzn` | 必須演習・標準演習・発展演習。`% TODO` が3か所ある |
| `small.dzn` | 基礎データ（4人・3日・日勤2名・夜勤1名） |
| `week.dzn` | 標準データ（8人・7日・日勤3名または2名・夜勤2名） |

`.dzn` はどちらも架空のデータである。実在する職場の勤務表でも勤務規則でもない。

## 実行する

手順は5行のカードに1か所だけまとめてある。
教材サイトの参考資料「MiniZinc 実行環境の使い方」の**手順カード（モデル + データ）**を見る。
Playground の画面が変わったときも、直すのはそのカード1か所である。

この回で使うのは次の組み合わせである。

- モデル: `roster.mzn`
- データ: `small.dzn`（必須演習）／ `week.dzn`（標準演習）

## 出力の読み方

```text
        1日 2日 3日
職員A   夜  休  夜
職員B   休  日  日
職員C   日  夜  休
職員D   日  日  日
日勤    2   2   2
夜勤    1   1   1
資格者  1   1   1
```

上が勤務表そのもので、下の3行が確認用の集計である。

- `日勤` `夜勤` … その日にその勤務へ入った人数。`.dzn` の `need_day` `need_night` と一致するか
- `資格者` … その日の夜勤に入った人のうち、リーダー資格を持つ人数

**制約を書き忘れていても解は出る。** 必ずこの3行で確かめること。

操作の詳細は教材サイトの「MiniZinc 実行環境の使い方」にある。
