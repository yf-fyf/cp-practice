# 第02回 論理グリッドの探索とモデル化（演習ファイル）

考え方・手順・ヒントは教材ページにある。ここには実行方法だけを書く。

- 教材ページ: [第02回](https://yf-fyf.github.io/cp-practice/sessions/02-prolog-modeling/)
- 実行ページ: [Prolog 実行環境](https://yf-fyf.github.io/cp-practice/tools/prolog/)

## ファイル

| ファイル | 使うところ |
|---|---|
| `choose.pl` | 必須演習。`% TODO` が5か所ある |
| `grid.pl` | 標準演習。名簿の並びと `permutation` まで書いてあり、手掛かりが `% TODO` |
| `coloring.pl` | 小さな実行例と発展演習 C。穴埋めは無い。そのまま実行する |

## 実行する

1. Prolog 実行ページをブラウザで開く。
2. `.pl` の中身をプログラム欄に貼り付ける。
3. クエリ欄に問い合わせを1行書いて「実行」を押す。
4. 別の解があるかを見るときは「次の解」を押す。

`grid.pl` は解が出るまでに数秒かかる。状態表示に経過時間が出る。
長引いたときは「中断」を押せば止まり、「次の解」で続きから再開できる。

## 実行ページのサンプル

実行ページの上部でサンプルを選べる。この回に対応するのは次の4つである。

| サンプル | 内容 |
|---|---|
| 第02回 リストと member | `choose.pl` の前半にあたる小さな例 |
| 第02回 論理グリッド（4人・3属性） | 標準演習の完成した形。自分で書き終えてから開く |

| 第02回 グラフ彩色（5地区・3色） | `coloring.pl` と同じ内容 |

## 書いたものを残す

実行ページの内容は**そのブラウザの中にしか残らない**。
別の端末には引き継がれず、履歴を消すと消える。
書けたものはこのディレクトリの `.pl` へ写して保存する。
